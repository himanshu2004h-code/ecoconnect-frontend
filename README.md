# EcoConnect frontend prototype

This is a standalone, responsive HTML/CSS/JavaScript prototype for the EcoConnect citizen, volunteer, and city-officer experience.

## Run locally

1. Extract this ZIP to a folder on your computer.
2. Open `index.html` in a modern web browser.

No build step, web server, package manager, or internet connection is required.

## Contents

- `index.html` — page structure and accessible content
- `styles.css` — responsive green-and-white visual design
- `app.js` — prototype interactions, filters, and status messages

## Salesforce status

This deliverable is a visual prototype only. It does not query or update Salesforce. UI labels reference the verified intended integration points (`Environmental_Issue__c` and `Green_Initiative__c`), while live data and actions remain pending a Salesforce DX/LWC deployment workflow.
